The Scaly REPL in the page

The Scaly compiler and LLVM, compiled to WebAssembly, running in this browser tab. Each entry is compiled to a WebAssembly module and loaded into the REPL's own memory, so what an entry binds is there for the next one. Nothing leaves the page. New to Scaly? Start in the Scaly Playground, watch one loop run on one core, on all of them and on the graphics card in the Mandelbrot showcase, or read about the language.
