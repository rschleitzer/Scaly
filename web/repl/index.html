The Scaly REPL in the page

The Scaly compiler and LLVM, compiled to WebAssembly, running in this browser tab. Each entry is compiled to a WebAssembly module and loaded into the REPL's own memory, so what an entry binds is there for the next one. Nothing leaves the page.
