Install Scaly

One command. It puts the compiler, the scaly tool and the language server on your machine, with the standard library and the standard packages.

Shown for .

> irm https://scaly.io/install.ps1 | iex
What the installer does
  • It installs Scaly into ~/.scaly (Windows: %USERPROFILE%\.scaly) and sets the PATH so the tools are found.
  • It installs Scaly into ~/.scaly and sets the PATH so the tools are found.

  • Building a program needs Apple's Command Line Tools. If they are missing, the installer fetches them and macOS asks for your password once.
  • Building a program needs a C compiler. If there is none, the installer fetches clang with apt and sudo asks for your password once.
  • Building a program needs the Visual Studio Build Tools. If they are missing, the installer fetches them (several GB, under Microsoft's license terms) and Windows asks for administrator rights once.
  • To uninstall, delete the .scaly directory and remove the PATH entry.
First steps
printf 'print("Hello, World!")\n' > hello.scaly
scaly run hello.scaly              # run it
scaly build hello.scaly -o hello   # build a program
scaly                              # the REPL (:help, :quit)
'print("Hello, World!")' | Set-Content hello.scaly
scaly run hello.scaly                  # run it
scaly build hello.scaly -o hello.exe   # build a program
scaly                                  # the REPL (:help, :quit)

Then: the tutorial, the language reference, and the VS Code extension.

Without the build tools

Running programs, tests and the REPL need none of them. If you do not want the installer to fetch anything, use this command instead of the one above:

$ curl -fsSL https://scaly.io/install.sh | SCALY_BUILD_TOOLS=skip sh
> $env:SCALY_BUILD_TOOLS = 'skip'; irm https://scaly.io/install.ps1 | iex
