Scaly, the self-scaling programming language — what is built with it, and open source tools for document processing.

The language
Scaly →

A compiled language whose memory is managed in regions the compiler infers: no garbage collector, no borrow checker, no lifetime annotations in ordinary code. Native code through LLVM, functions checked to be pure, and for loops that run on every core when their body allows it. Self-hosted, with a REPL, a build tool, packages from git, an HTTP stack, a language server and a VS Code extension, and source-level debugging.
