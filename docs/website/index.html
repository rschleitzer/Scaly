Scaly →

A self-scaling, self-hosted programming language with LLVM code generation, inferred region-based memory management, and a clean, semicolon-free syntax. Comes with a language server written in Scaly, a VS Code extension with syntax highlighting and full IDE features, and source-level debugging via DWARF.
